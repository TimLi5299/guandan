## R3 回滚原因（试过没用的结论）
- **花色记录**：唯一用途同花顺判断，同花顺仅占 0.4% 出牌 → 收益微乎其微，未实现。
- **过牌推断**：理论上"某家能跟却 pass → 它没更大的牌"有信息价值，但实测纯增量 **-0.8pp**（三种子一致 <50%）。根因：① 触发苛刻（需两个对手都 pass 过同型大牌）② **战术 pass 噪声**——对手有大牌但 pass（藏牌/让队友）时，推断"它没有"会误判无敌 → 出牌被压 → 亏。当前对手模型下噪声略大于信号。
- **方向性结论**：规则层（记牌/启发式）的边际改进空间已很小（master 对 expert 已 94.7%）。更大提升应转向结构性方向（PIMC 中盘采样 / 给 expert 档也上搜索 / 改进 S2-S3 采样质量），而非继续微调记牌。

## 难度阶梯标定（给 expert 上搜索 → 难度体系重设计）

### 关键结论
- **搜索 >> 规则微调**：给 expert 加 S2 残局精算 = **+30pp**（expertS2 vs expert：80.5/79.7/80.5% 三种子稳定，地板100%）。对比 R2 炸弹调参才 +2pp。
- **真 noob ≈ 随机地板**（46.7%）：之前"noob 100%"是台子 bug（arena 给所有档硬编码 level='expert'，noob 没走 decideNoob）。已修。
- **规则 AI 难度谱天然陡峭**：有脑子就碾压随机，失误率填不平 noob→normal 鸿沟（normal@0.6 还 97.5% vs noob）。
- **"vs 地板"在高档饱和**（都~100%），难度必须用相邻档对打标定。
